# Task 1. Spiral Matrix

Write a function that returns an `n` x `n` table filled with numbers from
1 to n<sup>2</sup> in a spiral that starts in the top-left corner and turns clockwise.

## For example

For `n` = `5`:

```json
[
  [ 1,  2,  3,  4, 5],
  [16, 17, 18, 19, 6],
  [15, 24, 25, 20, 7],
  [14, 23, 22, 21, 8],
  [13, 12, 11, 10, 9]
]
```
